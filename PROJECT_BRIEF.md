# Project Brief

This file defines the current project. It outranks stylistic suggestions in the Web Design OS.

## Project identity

- Project name: Operator (provisional wordmark)
- Business or product: AI-enabled website and software studio
- Site type: marketing / portfolio
- Current status: redesign / extension — Concept C opening prototype approved; full site not built yet

## Audience and outcome

- Primary audience: Owners and operators of growing businesses who have outgrown brochure sites and template tools
- Situation they are in when they arrive: Need a website that staff can update, customers can use, and that connects to operational data
- Main problem or desire: Stop decorating the business online; make the site run the business
- Primary action the site should drive: Start a project / request a consultation
- Secondary action: See how the operating model works (Site → Sheet → Live ops)
- What the visitor should understand or feel in the first 10 seconds: This studio builds systems that run businesses — not template pages

## Content and proof

- Real products, projects, services, or offers:
  - Premium websites
  - Websites connected to operational business data
  - Google Sheets-powered publishing systems
  - AI tools, internal portals, engineering software, customer workflows, dashboards, databases, booking systems, custom web applications
- Real evidence available:
  - HarnessMate (engineering software) — system diagram in prototype; live UI captures still pending
  - Hospitality / bar Sheets-powered sites — mentioned; captures pending
  - MyBird Real Estate — mentioned; captures pending
- Claims that are verified: Capability categories above as real work areas
- Claims that must not be made: Invented metrics, testimonials, awards, client outcomes, or fabricated product screenshots presented as truth
- Required pages or flows: Landing experience; consultation CTA
- Required sections or concepts (not necessarily one section each): Hero, operating model, HarnessMate proof, Sheets demonstration, MyBird proof, process, trust, consultation

## Visual identity

- Desired emotional effect: Grand, capable, modern — living systems, not cold enterprise sterility
- Brand traits: Spatial, technical, premium, memorable
- Traits to avoid: Generic dark purple SaaS glow; admin-dashboard “professional”; monospace micro-labels as the whole brand; hero card grids; thin-border documentation layouts
- References, screenshots, Figma frames, or URLs: Selected Concept C screenshots in `docs/visual-routes/prototype-c-*.png`
- What is admired in each reference: Spatial depth, kinetic field, monumental brand type, Site→Sheet→Live ops proof transition
- Existing logo, colors, fonts, imagery, or design system:
  - Provisional brand: Operator
  - Type: Space Grotesk + Newsreader
  - Palette: steel void, teal glow, warm accent
  - Atmosphere: `public/concepts/c-atmosphere.png`
  - Signature: cursor-reactive kinetic field
- Preferred or prohibited techniques, if any:
  - Prefer: spatial depth, custom SVG/diagrams, generative canvas, intentional motion
  - Skip Motion+ for now; use free `motion`
  - Phosphor for utility icons
