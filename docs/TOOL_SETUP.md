# Tool Setup and Roles

## shadcn MCP and skill

Use for accessible primitives, registry discovery, installation, and project-aware component patterns. It is a foundation, not the brand.

Project config is included in `.cursor/mcp.json`. Enable it manually in Cursor Settings → Tools & MCP. Install the official skill separately.

## 21st.dev

Use for visual discovery, themes, sections, templates, SVG assets, and meaningful route variants. Its role is to expand the model's visual vocabulary before custom composition.

The v2 workflow requires an actual search record at high design ambition. It does not require installing every result.

## Motion / Motion UI / AI Kit

Use the base Motion library for custom React animation. Motion UI and the AI Kit can supply polished sections, components, examples, transition tools, and motion analysis when available.

## React Bits

Use selectively for signature generative, shader, kinetic, cursor, gallery, or animated-block treatments. Current Pro distribution is shadcn-registry and Agent-Skill oriented. Do not assume a separate MCP is connected unless Cursor proves it in tool preflight.

## Cursor Design Mode

Use visual selection and direct on-canvas feedback after route prototypes exist. Mark specific areas and ask for compositional changes rather than sending another entire-site prose prompt.

## Cursor image generation

Use for brand illustrations, textures, conceptual backgrounds, and visual-route exploration. Generated images must not impersonate real client/product screenshots.

## Rule

A tool is “available” only after an actual tool call or CLI query succeeds. A tool is “used” only when its result appears in `docs/component-scout.md` or the implementation.
