# Stack Policy

## Default

- Existing framework and routing conventions
- TypeScript
- Semantic HTML and Tailwind/design tokens
- shadcn primitives as owned source
- Phosphor Icons
- Motion for React interaction and layout animation
- Cursor Browser for visual/runtime verification

## Conditional

- Anime.js: complex timeline, SVG, canvas, or imperative choreography
- Animista: copied and trimmed CSS keyframes only
- 21st.dev: candidate component discovery, followed by inspection and normalization
- Google Sheets: operational data source behind a typed server adapter
- Manus: separate agent/execution environment or portable skill consumer, not a frontend runtime dependency

## Avoid

- Multiple icon families in one product
- Multiple animation runtimes for the same interaction
- Unreviewed component dumps
- Client-side secrets
- Direct spreadsheet-cell logic in view components
- Framework migrations during a design task without a documented architectural need
