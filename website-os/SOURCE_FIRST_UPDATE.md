# Source-First Update

## Problem observed

A visually strong concept can still contain low-quality backgrounds, generic repeated boxes, weak icons, and basic motion. The prior workflow researched components during concept creation but did not force a second surface-by-surface sourcing and refinement pass after a concept was selected.

## Corrected model

```text
Brief
→ broad source scouting
→ compact visual routes
→ human or critic selects one route
→ signature-surface pass
→ asset-quality pass
→ responsive motion refinement
→ browser critique
→ full-site expansion
→ production QA
```

Concept routes should be good enough to compare, but production effort belongs primarily on the winner. Any placeholder in a concept must be explicitly marked and replaced before the selected route passes refinement.

## General principle

Hardcode the research and refinement process—not a universal set of components or a universal aesthetic.
