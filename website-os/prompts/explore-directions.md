# Explore Visual Directions

```text
/visual-directions

Use PROJECT_BRIEF.md and the supplied references.

Build three compact, materially different visual routes under isolated paths.
Each route must include:
- navigation;
- first screen;
- one representative section;
- one signature interaction;
- desktop and mobile states.

The routes must differ in composition, typography, color/material logic,
imagery, depth, navigation behavior, motion, and section rhythm—not merely
accent color.

Use the enabled MCPs and registries to research relevant raw materials. Record
serious candidates and do not install everything you preview.

Do not build the full website yet. Stop when all routes are rendered and ready
for screenshot-first comparison.
```
