# Visual Critique Prompt

```text
/browser-critique

Audit the rendered site, not only its source code.

Inspect screenshots before reading the design rationale. Review mobile and
desktop, navigation states, the first screen, representative sections, the
primary workflow, and signature motion.

Identify:
- what is immediately clear;
- what is visually specific to this project;
- what still looks generic or AI-generated;
- weak composition or hierarchy;
- repeated section patterns;
- weak imagery or fake-looking evidence;
- motion that helps or distracts;
- responsive layouts that were merely stacked;
- trust and conversion problems.

Rank findings by impact and recommend keep, refine, simplify, or replace.
```
