# Refine a Selected Direction

```text
The selected visual route is the approved source of visual truth, not a finished
site. Preserve its central composition, typography, material, imagery, navigation,
and motion logic.

Before expanding the complete experience:

1. run /signature-surface-pass;
2. run /asset-quality-pass where media or generated backgrounds matter;
3. run /motion-design for responsive, source-grounded motion;
4. run /browser-critique on the refined route.

Replace generic repeated boxes, low-quality backgrounds, weak placeholder imagery,
sluggish or desktop-only motion, and pasted-demo styling. For every high-impact
surface that needs redesign, run /visual-source-scout and preview serious external
candidates before custom-building.

Only after the selected route passes visual critique should its language be
expanded across the complete experience. Avoid repeating one layout pattern
everywhere. Use real assets and project evidence.
```
