# Autonomous Design Prompt

```text
/build-web-experience

Use autonomous design mode.

From PROJECT_BRIEF.md, create two or three compact visual routes internally.
Render each at mobile and desktop sizes. Have the visual critic inspect the
screenshots before reading the rationale and select the strongest route based
on project fit, clarity, originality, composition, proof, responsive potential,
motion potential, and implementation risk.

Continue with the selected route without waiting for approval unless the
comparison is genuinely inconclusive.

Do not merge all routes into a generic compromise. Build the complete site,
run browser critique, correct the findings, and complete production QA.
```
