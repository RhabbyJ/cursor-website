# Refine Selected Concept — Source-First Pass

```text
The selected concept is approved as the visual direction, but it is not yet a
finished design. Preserve its core typography, palette, atmosphere, composition,
and brand idea. Do not replace it with another unrelated concept.

Before expanding the complete site, run the required selected-direction gate:

1. /signature-surface-pass
2. /asset-quality-pass where imagery, backgrounds, canvas, shaders, video, or
   product screenshots matter
3. /motion-design
4. /browser-critique

Create a surface inventory covering navigation, hero/background, category or
service system, project surfaces, CTA, iconography, and section transitions.

For every signature surface that still looks like generic CSS, repeated boxes,
default icon-card UI, or a weak placeholder, run /visual-source-scout. Execute
real searches through at least two relevant available sources such as Aceternity,
21st, Motion UI / Motion AI Kit, Magic UI, React Bits Pro, shadcn registries, or
approved reference sites.

Do not use every source. Shortlist and preview candidates, then adopt and adapt
the strongest option into one coherent project language. Custom implementation
is allowed only after documenting why the sourced candidates are weaker or
inappropriate.

Treat responsive motion as a design problem. Define fine-pointer hover, keyboard
focus, touch, narrow-screen, reduced-motion, and lower-power fallbacks. Tune
springs and input response so interactions feel immediate rather than delayed.

Audit important imagery and backgrounds for intrinsic resolution, scaling,
compression artifacts, device-pixel-ratio handling, mobile crop, and fallbacks.
Regenerate or replace weak source assets rather than hiding them with blur.

Render and inspect the refined selected route at mobile, laptop, and wide desktop
sizes. Stop after the selected route passes visual critique. Do not build the
remaining site yet.
```
