# Repeated Surface Lab

```text
/signature-surface-pass

Focus only on the selected concept's repeated category, service, feature, or
project surface. Do not redesign the hero or the rest of the page.

The current repeated surface looks like generic CSS boxes. First question whether
cards are the right composition at all.

Run /visual-source-scout and execute real searches through at least two relevant
available sources. Explore materially different patterns such as animated
editorial lists, expanding panels, spotlight or focus systems, image-led tiles,
spatial maps, draggable collections, scroll-linked sequences, or responsive
bento systems.

Build three isolated variants using real project content:
- Variant A: [source/pattern]
- Variant B: [source/pattern]
- Variant C: [source/pattern]

Each variant must include desktop, keyboard, touch/mobile, hover where applicable,
and reduced-motion behavior. Adapt typography, color, proportions, iconography,
and motion to the selected concept. Do not paste demo styling unchanged.

Use the visual critic to select the strongest variant from rendered screenshots
and interactions. Stop after the surface variant is selected and integrated into
the selected concept.
```
