# Motion Pass Prompt

```text
/motion-design

Review the approved static composition and define a motion system for this
specific project.

Do not add blanket fade-up animation. Identify:
- one signature motion experience;
- supporting transitions;
- microinteractions;
- state changes;
- reduced-motion alternatives.

Choose CSS, Motion, GSAP, Anime.js, Lenis, WebGL, or another technique only
where it is the best fit. Do not use multiple systems on the same properties.
Test the real browser result for pacing, jank, accessibility, and mobile
performance.
```
