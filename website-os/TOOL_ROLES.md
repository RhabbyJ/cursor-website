# Tool Roles

## shadcn/ui

Use for accessible primitives, forms, dialogs, navigation behavior, and registry infrastructure. It also provides namespaced registry and MCP access for sources such as Aceternity. Customize the source. Do not let default shadcn styling become the brand.

## Aceternity UI

Use for expressive backgrounds, hero treatments, navigation, spatial effects, animated cards, marquees, 3D-style treatments, and other high-impact marketing interactions. Add it as a namespaced shadcn registry and search or preview before installing. Do not turn every site into the same spotlight/bento/floating-dock template.

## 21st

Use for broad discovery across components, themes, templates, SVG assets, marketing blocks, navigation, galleries, shaders, and interaction patterns. Use it to widen the option space, not to assemble unrelated components from many authors.

## Magic UI

Use for effects and marketing primitives such as backgrounds, beams, particles, text treatments, marquees, animated lists, device frames, and interactive buttons. Use the effect only when it supports the selected concept.

## Motion

Use as a strong default for React layout, gesture, pointer-responsive, scroll, and component motion. The normal Motion library is sufficient for many projects.

## Motion UI / Motion AI Kit / Motion+

Optional paid tooling for polished animated sections, current Motion examples, spring generation, transition editing, and performance auditing. Particularly useful during the selected-direction motion refinement pass.

## React Bits Pro

Optional paid source registry for shaders, backgrounds, cursors, 3D, animated components, blocks, and full templates. It can raise the visual ceiling when used with a strong art direction. Its registry and Skill require a license.

## Phosphor Icons

A broad utility icon family. Use for interface consistency. It does not need to carry the brand. Custom SVG, logos, diagrams, illustration, animated icons, or 3D may provide the storytelling layer.

## Cursor Browser

Native verification surface for real layout, interactions, responsive behavior, console output, network failures, and visual critique. It is not an MCP that must be installed.

## Cursor image generation

Useful for project-specific illustration, textures, atmospheres, and concept art. Generate at sufficient resolution for the intended render. Generated art must not be presented as real product, client, team, or performance evidence.

## Anime.js, GSAP, Lenis, Three.js, React Three Fiber

Install only when the selected interaction or visual concept justifies them. The Motion Skill contains a routing guide.
