# Launch Checklist

## Product and content

- [ ] Primary action is clear and works.
- [ ] Public claims are verified.
- [ ] No placeholder copy, fake proof, or invented interfaces remain.
- [ ] Real contact, privacy, legal, and business details are present where required.

## Visual

- [ ] Final browser screenshots were reviewed.
- [ ] Navigation and first screen are intentional on mobile and desktop.
- [ ] Real project/media assets are optimized and correctly cropped.
- [ ] Motion supports the concept and has reduced-motion behavior.
- [ ] No abandoned component styles or experimental dependencies remain.

## Accessibility

- [ ] Keyboard navigation works.
- [ ] Focus is visible.
- [ ] Semantics and heading order are correct.
- [ ] Forms and errors are labeled and announced.
- [ ] Contrast and touch targets are acceptable.
- [ ] Important meaning does not depend only on color, hover, sound, or animation.

## Runtime

- [ ] Console has no unexplained errors.
- [ ] Critical network requests succeed.
- [ ] Loading, empty, error, and success states work.
- [ ] Links and routes work.
- [ ] Mobile and target browsers were tested.

## Engineering

- [ ] Formatting passes.
- [ ] Lint passes.
- [ ] Typecheck passes.
- [ ] Tests pass where present.
- [ ] Production build passes.
- [ ] Secrets are not exposed.
- [ ] Performance and heavy visual effects have appropriate fallbacks.
