# Asset Inventory

Create `docs/asset-inventory.md` and inspect the actual files.

Classify every material asset as:

- **real product evidence** — screenshot, recording, live URL, exported UI;
- **brand asset** — logo, type, palette, photography, illustration;
- **generated brand art** — decorative or conceptual, not product proof;
- **reference only** — inspiration that cannot be copied;
- **placeholder** — must be replaced before final acceptance.

For each featured project, record:

- live URL or source path;
- available desktop/mobile screenshots;
- project status;
- what the image truthfully proves;
- missing evidence.

## Portfolio gate

A portfolio/case-study section cannot receive final visual approval with only fabricated CSS UI or an unlabeled placeholder. Use a clearly labeled placeholder during route exploration, then replace it with real evidence.

Cursor image generation may create brand art, textures, illustrations, or conceptual backgrounds. It must not fabricate a fake customer product and present it as completed work.
