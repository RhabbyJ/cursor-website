# Component Research

Use `/visual-source-scout` for mandatory high-impact surface research. Use this Skill for broader component evaluation and adoption.

## Search by role

Examples:

- animated navigation;
- image-led hero;
- shader or light-field background;
- non-generic category system;
- scroll-linked project showcase;
- comparison interaction;
- gallery;
- marquee;
- booking interface;
- accessible command menu;
- responsive data visualization.

Avoid searches such as “make it cool” or “premium website component.”

## Source roles

- existing project components and private registry for proven internal patterns;
- shadcn for accessible foundations and namespaced registry access;
- Aceternity UI for expressive backgrounds, heroes, navigation, spatial effects, animated cards, and marketing interactions;
- 21st for broad multi-author design discovery, components, themes, templates, and SVG assets;
- Motion UI / Motion AI Kit for polished animated sections, interaction examples, springs, and audits;
- Magic UI for animated effects, backgrounds, text treatments, lists, and marketing primitives;
- React Bits Pro when licensed for shaders, 3D, cursors, animated components, blocks, or templates;
- custom implementation when the concept is unique or adoption cost is too high.

## Evaluate candidates

For each serious candidate, inspect:

- visual fit;
- behavior and states;
- accessibility;
- responsiveness;
- dependency weight;
- performance risk;
- licensing or authentication;
- source ownership;
- adaptation effort.

Do not install several candidates merely to compare them. Preview first when possible.

## Adaptation

After adoption:

- replace demo content;
- align tokens, typography, spacing, material, and iconography;
- preserve the useful interaction quality;
- remove unnecessary dependencies and effects;
- verify keyboard, touch, and reduced-motion behavior;
- inspect the real render.

Record searches, candidates, decisions, and licenses in `website-os/work/source-scout.md` or `website-os/work/tool-log.md`.
