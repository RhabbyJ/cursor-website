# Visual Directions

Use when the project has no approved visual target or when several directions would be valuable.

## Research

- Inspect supplied references and real assets.
- For high-ambition or expressive projects, run `/visual-source-scout` before implementing each route's signature surfaces.
- Search separately for navigation, typography, image treatment, background/depth, repeated-content systems, project presentation, and motion—not only full templates.
- Do not copy a single source wholesale.

## Create two or three routes

Each route must define:

- central visual idea;
- first-screen composition;
- navigation behavior;
- typography character;
- color and material logic;
- imagery or generative-art approach;
- representative category, service, feature, or project system;
- signature interaction;
- motion grammar;
- responsive strategy;
- risks and dependency cost.

Routes must be genuinely different. A palette or border-radius change is not a new direction.

For visual ambition 7 or higher, each route must contain at least:

- one source-backed or genuinely bespoke signature visual primitive;
- one representative repeated-content surface that is not a generic placeholder grid;
- one meaningful interaction beyond simple fade-up entrance animation.

## Render, do not merely describe

For each route, build:

- navigation;
- hero or primary surface;
- one representative repeated-content or product section;
- one interaction;
- desktop and mobile screenshots.

Concept routes may remain compact, but any intentionally unfinished surface must be labeled as a placeholder and cannot pass selected-direction refinement.

## Selection and refinement

In `explore` mode, present the routes for user selection.

In `autonomous` mode, ask the visual critic to compare brand fit, first-screen impact, originality, clarity, content compatibility, responsive potential, motion potential, and implementation risk.

After selection, do not expand the entire site immediately. Run `/signature-surface-pass`, `/asset-quality-pass` when media is important, and `/motion-design` on the winning route first.
