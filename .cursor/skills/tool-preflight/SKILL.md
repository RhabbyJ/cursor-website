# Tool Preflight

Create `docs/tool-preflight.md`.

## Verify, do not assume

For each source below, record:

- configured location;
- enabled/connected status;
- actual command or tool call used;
- one successful search/result;
- authentication or licensing limitation;
- whether it is approved for this project.

Check when relevant:

- shadcn MCP and official skill;
- 21st.dev MCP/CLI;
- Motion AI Kit / Motion UI catalogue;
- React Bits registry/skill;
- private registries;
- Cursor Browser and Design Mode;
- Cursor image generation;
- local asset directories.

## Minimum discovery at design ambition 7+

Before custom-building all visual primitives, search at least two relevant sources for:

- hero composition;
- project/case-study treatment;
- signature motion or background treatment;
- navigation/CTA only when needed.

Search is mandatory; installation is not. Record candidate names, references, dependencies, and rejection reasons.

If a tool is unavailable, mark it unavailable and continue with another source. Never claim that an MCP was used when no tool call or CLI result exists.
