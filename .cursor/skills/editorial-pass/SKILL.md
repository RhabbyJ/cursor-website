# Editorial Pass

Review the rendered page and all public copy.

## Remove

- repeated restatements of the positioning;
- internal guardrails, evidence policies, or implementation caveats that leaked into marketing copy;
- section headings that merely describe the section type;
- generic service lists that do not help a buyer choose;
- paragraphs that a real screenshot, interaction, or diagram already proves;
- UI elements present only because the prompt mentioned them.

## Target

Normally reduce first-draft public copy by 25–35% while preserving essential information.

No two adjacent sections should answer the same user question. Merge or delete sections that do.

Rewrite for concrete business outcomes, specific nouns, active verbs, and truthful project status. Do not add invented proof to compensate for missing evidence.
