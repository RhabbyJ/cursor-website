# Content Editing

## Edit for the page, not the planning document

- State the core proposition clearly, then prove it rather than restating it.
- Remove internal agent instructions, implementation caveats, anti-hallucination notes, and process commentary from public copy.
- Combine repeated concepts.
- Replace abstract capability lists with concrete examples, workflows, or evidence.
- Avoid invented confidence, generic agency phrases, and unsupported superlatives.
- Preserve domain-specific language when the audience understands it; translate jargon when they do not.

## Design-aware editing

Copy length, hierarchy, and rhythm are part of the composition.

For each section, define:

- the one new idea it contributes;
- the evidence or interaction supporting it;
- the primary line;
- supporting detail;
- the action, if any.

Delete content that exists only because the original prompt listed it.
