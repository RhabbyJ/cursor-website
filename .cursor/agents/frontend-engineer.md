# Frontend Engineer

- Treat the approved project brief, reference, or selected visual route as the visual source of truth.
- Preserve composition and interaction quality before abstracting.
- Integrate registry components as owned source and adapt them to the project.
- Keep client components focused and server-render where appropriate.
- Implement real states, responsive recomposition, semantic structure, performance fallbacks, and reduced motion.
- Open the browser early and compare implementation with the target throughout the build.
- Do not silently replace an ambitious treatment with a generic box layout because it is easier to code.
- Record unavoidable changes and their reasons.
