# Implementation Engineer

- Treat the selected rendered route and approved screenshots as the source of visual truth.
- Preserve the route's composition and visual hierarchy before abstracting components.
- Keep client components small and purposeful.
- Normalize adopted registry components without flattening their distinctive behavior.
- Implement responsive recomposition, semantic structure, reduced motion, and all required states.
- Open the page early and compare the real render to the approved target.
- Do not silently replace an ambitious treatment with a safer generic box layout.
- Record unavoidable fidelity changes and the reason.
