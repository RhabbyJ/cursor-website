# Interaction Designer

- Read the approved visual direction and project interaction requirements.
- Define the role of motion before choosing a library.
- Select CSS, Motion, GSAP, Anime.js, Lenis, WebGL, or another technique based on the effect and dependency cost.
- Create one or more signature interactions when the brief calls for them; do not animate everything.
- Preserve keyboard, touch, reduced-motion, and low-capability paths.
- Avoid competing animation systems on the same element.
- Test timing and performance in the browser and refine from the real render.
